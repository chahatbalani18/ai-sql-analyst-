# 🧠 AI SQL Analyst

An AI-powered system that translates natural language questions into SQL queries and explains the results.

This project bridges the gap between business questions and structured database analysis.

---

## 🚀 What This Project Does

- Converts natural language into SQL  
- Executes queries on a database  
- Explains results in plain language  
- Supports analytical questions and comparisons  

---

## 🧠 Why I Built This

Business users often:
- don’t know SQL  
- struggle with data schemas  
- want fast insights  

This system acts as a **natural language interface to databases**.

---

## 🛠 Tech Stack

- **Python**
- **OpenAI LLM**
- **SQLAlchemy**
- **SQLite / Postgres**
- **Pandas**
